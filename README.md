# Kick DocsHub

Interni hub za timsku dokumentaciju (Kick). Statična stranica — pretraga, boje po timovima, direktni linkovi ka Google Docs/Sheets/Slides.

## Objava na GitHub Pages
1. Napravi repo na github.com (npr. `docshub`).
2. Poveži i push-uj (komande ispod).
3. Repo → Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/root` → Save.
4. Sajt će biti na `https://<korisnicko-ime>.github.io/docshub/`.

Sadržaj je u `index.html`.
